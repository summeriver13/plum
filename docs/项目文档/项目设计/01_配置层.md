# 01_配置层设计

配置层位于 `app/config/`，负责集中管理项目的所有配置项，为其他层提供统一、类型安全的配置访问接口。

> **核心原则**：配置层是基础设施，被所有其他层依赖，但不依赖任何业务层。

---

## 零、架构概览

配置层采用 **数据与逻辑分离** 的设计：

- **`config.toml`**：静态配置文件，存储默认值和可配置参数
- **`settings.py`**：配置加载、验证、合并逻辑
- **`__init__.py`**：对外暴露统一入口

```
调用方（规则层/数据层/引擎层/策略层...）
    │
    ▼
app.config.get_config()
    │
    ├──► settings.py  (加载 TOML → 合并环境变量 → 验证 → 返回)
    │
    └──► config.toml  (默认配置值)
```

---

## 一、配置文件 (`config.toml`)

`config.toml` 是**静态配置文件**，使用 TOML 格式存储项目的默认配置值。TOML 语义明确、结构清晰，适合做项目配置。该文件放在 `app/config/` 目录下，由 `settings.py` 通过 `tomllib`（Python 3.12 内置）读取解析。

### 1.1 配置分组

配置文件按业务模块分组，避免命名冲突：

```toml
[project]
name = "plum"
env = "dev"  # dev / test / prod
debug = true

# 数据源配置
[data]
db_path = "./data"
bar_format = "parquet"  # parquet / csv
validate_on_load = true

[data.bao_stock]
enabled = true

[data.xt_data]
enabled = false
xt_path = ""  # MiniQMT 路径，敏感信息走环境变量

# 交易成本配置（影响回测真实性）
[cost]
commission_rate = 0.00025  # 佣金率（万分之2.5）
min_commission = 5.0       # 最低佣金（元）
stamp_tax = 0.0005         # 印花税（卖出单边）
transfer_fee = 0.00001     # 过户费
slippage = 0.0             # 滑点（元）

# 风控与限制
[risk]
max_position_pct = 0.1     # 单票最大持仓占比
max_drawdown = 0.2         # 最大回撤限制
limit_up_deal = false      # 涨停是否排队成交
limit_down_deal = false    # 跌停是否排队成交

[rule]
cache_enabled = true

[engine]
backtest_start = "2020-01-01"
backtest_end = "2024-12-31"
initial_capital = 1000000

[strategy]
default = "buy_and_hold"

# 策略参数示例（均线周期等）
[strategy.macross]
fast_period = 5
slow_period = 20

[logging]
level = "DEBUG"
format = "rich"  # rich / json / text
```

### 1.2 多环境支持

通过环境变量 `PLUM_ENV` 切换环境，加载对应配置：

```toml
# 可通过环境变量覆盖
[project]
env = "${PLUM_ENV:dev}"
```

## 二、配置加载 (`settings.py`)

使用 Python 3.12 内置的 `tomllib` 解析 `config.toml`，无需额外依赖。

### 2.1 核心类

```python
from dataclasses import dataclass, field
from pathlib import Path

@dataclass
class ProjectConfig:
    name: str = "plum"
    env: str = "dev"
    debug: bool = False

@dataclass
class DataConfig:
    db_path: str = "./data"
    bar_format: str = "parquet"
    validate_on_load: bool = True

@dataclass
class CostConfig:
    commission_rate: float = 0.00025
    min_commission: float = 5.0
    stamp_tax: float = 0.0005
    transfer_fee: float = 0.00001
    slippage: float = 0.0

@dataclass
class RiskConfig:
    max_position_pct: float = 0.1
    max_drawdown: float = 0.2
    limit_up_deal: bool = False
    limit_down_deal: bool = False

@dataclass
class RuleConfig:
    cache_enabled: bool = True

@dataclass
class EngineConfig:
    backtest_start: str = "2020-01-01"
    backtest_end: str = "2024-12-31"
    initial_capital: int = 1_000_000

@dataclass
class StrategyConfig:
    default: str = "buy_and_hold"
    params: dict = field(default_factory=dict)

@dataclass
class LoggingConfig:
    level: str = "DEBUG"
    format: str = "rich"

@dataclass
class Settings:
    project: ProjectConfig = field(default_factory=ProjectConfig)
    data: DataConfig = field(default_factory=DataConfig)
    cost: CostConfig = field(default_factory=CostConfig)
    risk: RiskConfig = field(default_factory=RiskConfig)
    rule: RuleConfig = field(default_factory=RuleConfig)
    engine: EngineConfig = field(default_factory=EngineConfig)
    strategy: StrategyConfig = field(default_factory=StrategyConfig)
    logging: LoggingConfig = field(default_factory=LoggingConfig)
```

### 2.2 加载流程

```
1. 读取 config.toml 默认值
2. 读取环境变量（优先级高于 TOML）
3. 合并配置到 Settings 对象
4. 验证必填项和格式
5. 返回单例 Settings 实例
```

### 2.3 环境变量覆盖规则

- 环境变量命名格式：`PLUM_<SECTION>_<KEY>`
- 示例：`PLUM_DATA_DB_PATH=/custom/path` 覆盖 `data.db_path`
- 环境变量优先级 **高于** TOML 配置文件
- 敏感信息（如 API Key、Broker 账号）必须通过环境变量注入

## 三、使用方式

### 3.1 获取配置

```python
from app.config import get_config

config = get_config()

# 访问配置项
db_path = config.data.db_path
initial_capital = config.engine.initial_capital
commission = config.cost.commission_rate
debug = config.project.debug
```

### 3.2 配置验证

启动时验证关键配置项，失败则快速报错：

```python
def validate_settings(settings: Settings) -> None:
    if not settings.data.db_path:
        raise ValueError("data.db_path 不能为空")
    if settings.engine.initial_capital <= 0:
        raise ValueError("engine.initial_capital 必须大于 0")
    if not (0 < settings.cost.commission_rate < 1):
        raise ValueError("commission_rate 必须在 0~1 之间")
    if not (0 < settings.risk.max_position_pct <= 1):
        raise ValueError("max_position_pct 必须在 0~1 之间")
```

---

## 四、敏感信息处理

- **不要**将密码、API Key、Broker 账号等敏感信息写入 `config.toml`
- 敏感信息应通过环境变量或 `.env` 文件注入
- `.env` 文件仅用于本地开发，不提交到版本控制（加入 `.gitignore`）

---

## 五、策略参数动态化

支持策略从配置中读取参数，实现"改配置不更代码"：

```toml
[strategy.macross]
fast_period = 5
slow_period = 20
```

```python
# 策略中读取参数
params = config.strategy.params
fast = params.get("fast_period", 5)
slow = params.get("slow_period", 20)
```
