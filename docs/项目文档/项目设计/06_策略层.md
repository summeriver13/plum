# 05_策略层设计

## 1. 策略的本质
   - 策略 = 交易逻辑的封装
   - 与引擎的关系：引擎驱动策略（回调），策略不主动控制时间

## 2. 策略生命周期
   - 初始化（`__init__` 或 `on_init`）：加载参数、预加载数据、设置状态
   - 盘中回调：`on_bar`, `on_tick`
   - 订单回调：`on_order`, `on_trade`
   - 盘后/收盘：`on_close`
   - **状态持久化**：策略变量如何保存与恢复（用于实盘重启）

## 3. 策略基类接口
   - 定义 `Strategy` 抽象基类（代码示例）
   - 各回调方法的参数说明（`bar: Bar`, `context: Context`）
   - **context 结构详解**（包含 `current_date`, `universe`, `portfolio`, `current_data` 等）
   - 如何访问因子引擎（`self.factors`）
   - 如何访问账户/持仓信息（`self.broker`）
   - 如何访问规则引擎（可选，`self.rules`）

## 4. 策略与因子层的集成
   - 通过 `FactorEngine` 获取因子值
   - 示例：`rsi = self.factors.get('RSI', symbol='000001.SZ', period=14)`
   - 因子缓存与性能考虑

## 5. 策略配置
   - 使用 `config.toml` 管理策略参数
   - 参数示例：`fast_period = 5`, `slow_period = 20`
   - 如何在策略中读取配置

## 6. 编写第一个策略（示例）
   - 双均线策略（金叉买入，死叉卖出）
   - 包含：初始化、on_bar 逻辑、下单、**简单错误处理**（如资金不足）
   - 展示如何调用因子（SMA）和规则引擎（可选）

## 7. 策略调试与日志
   - 使用 `loguru` 或 `rich.logging` 输出关键信息
   - 保存每日快照（持仓、净值）
   - **常见调试技巧**（如打印信号、条件断点）

## 8. 策略的测试
   - 单元测试：用 Mock 因子和 Mock 账户测试策略逻辑
   - 回测验证：通过回测引擎运行完整历史数据

## 9. 策略的维护与版本管理
   - 策略目录结构（每个策略一个子目录，含 `__init__.py` 和 `config.toml`）
   - 策略命名规范
   - 如何废弃旧策略并迁移
