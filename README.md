# Plum

> 梅花香自苦寒来。

Plum 是按 A 股交易制度建模的回测与实盘一体化框架。它把「制度约束」当作一等公民：
板块涨跌停、T+1 交收、停牌与退市清算、冲击成本、财务数据 PIT，全部在引擎里显式建模，
而不是留给策略自己兜底。

## 这个仓库有什么

| 层 | 路径 | 内容 |
| --- | --- | --- |
| 规则层 | `app/rule/` | 涨跌停按板块判定、费用与印花税、除权除息、停牌 |
| 数据层 | `app/data/` | 行情/财务存储、连接器（QMT、baostock）、字段规范化、数据湖同步 |
| 因子层 | `app/factors/` | 因子基类、DSL、中性化、原生因子实现 |
| 引擎层 | `app/engine/` | 回测循环、组合与撮合、冲击模型、绩效分析、实盘网关 |
| 策略层 | `app/strategy/` | 策略 Protocol 与原生示例策略（低估值、ETF 轮动、时序趋势） |
| 入口 | `main.py` | `run --strategy <类路径>`，预设名从 `app/config/strategies.toml` 读取（可选） |

## 几个关键取舍

- **涨跌停按板块**：先剥交易所前缀再判幅度，创业板/科创板 20%、ST 5%，否则会给合法的 +20% 买单制造幽灵拒单。
- **成交额约束**：单笔不超过当日成交额的一定比例，叠加平方根冲击模型（`app/engine/backtest/scenarios/impact.py`）。
- **退市即清算**：退市注册表驱动，持仓按最后收盘价结清，不用「永不卖出」掩盖亏损。
- **财务数据 PIT**：按公告日对齐，避免用未来财报做当期决策。
- **金额用 Decimal**：撮合与账本不走 float，报表再转 float 展示。

## 安装

需要 Python 3.12。依赖用 [uv](https://docs.astral.sh/uv/) 管理：

```bash
uv sync
uv run pytest -q
```

`xtquant`（QMT SDK）只有 Windows 版；只做回测、不接 QMT 时，数据层里与它相关的三个模块不会被导入。

仓库默认走 PyPI。国内网络可临时换镜像，不必改配置：

```bash
UV_DEFAULT_INDEX=https://pypi.tuna.tsinghua.edu.cn/simple uv sync
```

## 数据

仓库不含行情数据。回测读取 `data/market/1d/{SH,SZ,IDX}/*.parquet`，由 `scripts/build_plum_market_from_qdata.py`
从数据湖重建。没有数据湖时，`tests/` 里的用例仍可完整跑通（它们用合成数据）。
